# `ui/academic/views.js`

The two list pages beside the Library. **Sources of Sources** shows containers grouped by
access (Immediately accessible, Account required, Paywall, Application inaccessible,
Unknown), each with its count, a one-line meaning and rows with provenance, "Browse
contents" (Library filtered by that container) and "Open". **Review queue** has jump
buttons and three paginated sections: sources awaiting review, pending editorial
notices and unreviewed claims; each row navigates to the item.
