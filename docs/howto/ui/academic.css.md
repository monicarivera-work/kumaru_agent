# `ui/academic.css`

Scoped dashboard styles extending the tokens in `styles.css`; no build step,
new fonts or framework. Desktop uses source/evidence panes; narrow screens stack
them. Forms and dynamic metadata wrap, including expanded JSON histories.
Operator copy uses accessible contrast, visible keyboard focus and native
controls. Motion respects reduced-motion preferences.

When editing, inspect both desktop and mobile in one bounded round. Preserve
chat's styles: changes belong under `.academic` or dashboard-specific selectors.
[HTML structure](academic.html.md), [behavior](academic.js.md).
